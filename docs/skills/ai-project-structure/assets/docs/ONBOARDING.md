# ONBOARDING

Guia rapido para entender este projeto.

## Para Humanos

1. Comece por `README.md`.
2. Entenda o contexto em `PROJECT_CONTEXT.md`.
3. Veja o que esta pendente em `TASKS.md`.
4. Consulte `SESSION.md` para saber o que a IA fez recentemente.
5. Leia `DECISIONS.md` antes de mudar uma decisao existente.

## Para Agentes De IA

1. Leia `../AGENTS.md`.
2. Siga a ordem de leitura indicada nele.
3. Antes de editar, confira `SESSION.md`.
4. Consulte `MEMORY.md` para aprendizados persistentes antes de tomar uma decisao.
5. Depois de trabalho relevante, atualize `SESSION.md`.
6. Ao concluir tarefa, registre a evidencia exigida em `TASKS.md`.
7. Quando faltar resposta que trava o trabalho, mova a tarefa para "Aguardando Usuario" em `TASKS.md`.
8. Use `CONSENSUS.md` quando houver duvida importante.

## Primeira Configuracao De Um Projeto Real

- Preencher objetivo e publico em `PROJECT_CONTEXT.md`.
- Preencher tarefas iniciais em `TASKS.md`.
- Registrar decisoes ja tomadas em `DECISIONS.md`.
- Documentar arquitetura inicial em `ARCHITECTURE.md`.
- Definir comandos de validacao em `QUALITY.md`.
