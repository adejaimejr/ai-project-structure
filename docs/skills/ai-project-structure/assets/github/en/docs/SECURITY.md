# Security Policy

## Supported versions

Only the latest published version (the most recent tag) receives fixes.

| Version         | Supported |
| --------------- | --------- |
| Latest release  | Yes       |
| Older releases  | No        |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through a Private Security Advisory: open the Security tab of this repository and choose "Report a vulnerability".

Include the version, the operating system, the steps to reproduce and the impact you see. We will reply as soon as we can and keep you informed until the issue is fixed.
