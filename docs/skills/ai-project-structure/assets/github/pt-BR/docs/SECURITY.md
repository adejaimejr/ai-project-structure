# Politica de Seguranca

## Versoes suportadas

Somente a ultima versao publicada (a tag mais recente) recebe correcoes.

| Versao            | Suportada |
| ----------------- | --------- |
| Ultima release    | Sim       |
| Releases antigas  | Nao       |

## Como reportar uma vulnerabilidade

Por favor, nao abra uma issue publica. Reporte em privado por um Private Security Advisory: abra a aba Security deste repositorio e escolha "Report a vulnerability".

Informe a versao, o sistema operacional, os passos para reproduzir e o impacto que voce ve. Vamos responder assim que possivel e manter voce informado ate a correcao do problema.
